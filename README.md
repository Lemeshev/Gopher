# 🐹 Gopher Life

Игра-питомец с маскотом-гофером: чистый **HTML5 Canvas + vanilla JS**, упакованный в **Android WebView**.
Никаких фреймворков и сборщиков фронтенда — открывается и как веб-страница, и как APK.

## Возможности

- **15 локаций на карте**: дом, магазин, работа, учёба, ресторан, бассейн, парк,
  поликлиника, музеи (4 зала), библиотека, кино, спортзал, друзья, мини-игры, инфо
- **База контента из 890 предметов** (`game_content.js`): по 100 экспонатов в каждом
  музее, 100 книг, 60 заданий на работе, 60 тем в учёбе и т.д. Каждое посещение —
  свежая подборка из 6 предметов с листанием, приоритет отдаётся ещё не виденным
- **Коллекция и факты**: у каждого предмета свой факт и своя награда; прогресс
  «изучено N из M» виден в статистике
- **Дом-конструктор**: покупки из магазина сразу появляются в комнате, мебель
  можно перетаскивать, убирать в инвентарь и ставить заново; обои и пол
  перекрашиваются бесплатно (6 обоев × 5 полов)
- **Живые действия дома**: покормить (гофер жуёт, летят крошки), искупать
  (лейка, брызги, пузырьки, лужа), играть (мячик прыгает по комнате),
  спать — энергия растёт постепенно, полный сон ровно 10 минут, есть «Разбудить»
- **Гофер выглядит по месту**: в бассейне плавает в круге и плавках, на работе
  в галстуке, в спортзале с повязкой и гантелей, в библиотеке в очках с книгой
- **Друзья и гости**: знакомство, рост дружбы, подарки; в гостях видно реальную
  комнату друга — её обои, пол и расстановку мебели; обмен кодами для друзей
  по переписке (комната едет вместе с кодом)
- **Профили**: до 4 гоферов на одном устройстве, у каждого свой окрас, комната
  и прогресс; гоферы с этого устройства видны в друзьях и ходят друг к другу
- 7 характеристик питомца (счастье, сытость, энергия, здоровье, чистота, стресс, интеллект)
- Уровни и XP-прогресс, монеты, достижения, 6 окрасов гофера и аксессуары
- Смена времени суток, офлайн-прогресс, автосохранение в `localStorage`
- Звук на Web Audio API (генерируется кодом, без аудиофайлов)

## Структура

```
www/                     исходники игры (открываются в браузере как есть)
  index.html             точка входа, вызывает new Game().init()
  css/style.css
  js/helpers.js          утилиты рисования (roundRect, createButton, ...)
  js/gopher.js           маскот
  js/system.js           характеристики, сохранения, достижения
  js/audio.js            синтез звуков
  js/game_content.js     база контента (890 предметов), мебель, обои, окрасы
  js/game_room.js        общий рендер комнаты (дом игрока и комнаты друзей)
  js/game_scenery.js     сцены локаций: гофер в правильном виде и обстановке
  js/game_menu.js        + game_map / game_home / game_shop
  js/game_minigames.js   + game_stats / game_clinic
  js/game_visit.js       экраны посещений (музеи, работа, бассейн, кино, …)
  js/game_friends.js     друзья, гости, комнаты друзей, обмен кодами
  js/game.js             ядро: цикл, ввод, перетаскивание, переходы сцен, туториал
android/                 обёртка WebView + ресурсы (иконка)
tools/verify.js          приёмка качества (5 ревьюеров, 75+ проверок)
tools/sync-www.js        копирование www/ → assets/www/ (вызывается сборкой)
tools/render-check.js    ревьюер реального рендера: игра запускается в Chrome,
                         снимаются пиксели канваса и скриншоты всех сцен
tools/shots/harness.html стенд для render-check (открывает сцену по #hash)
tools/render-gopher.js   рендер маскота в SVG для визуальной проверки
preview/                 готовые превью иконки, маскота и экранов игры
```

`android/app/src/main/assets/www/` — **копия** `www/`. Не копируйте руками:
`npm run sync` (сборка `npm run build` делает это сама, иначе APK уедет со старым кодом).

## Быстрая проверка в браузере (без сборки)

```bash
cd www && python3 -m http.server 8080
# открыть http://localhost:8080
```

## Сборка APK

```bash
npm run build          # подписанный release: android/app/build/outputs/apk/release/app-release.apk
npm run apk:desktop    # собрать и выложить на рабочий стол как Gopher.apk
```

Итоговый файл для заказчика называется **`Gopher.apk`** и лежит на рабочем столе
(`node tools/copy-apk.js` кладёт его туда и сверяет md5 с собранным).

### Подпись

Секреты **не хранятся в репозитории**. Создайте `android/keystore.properties`
по шаблону `android/keystore.properties.example`:

```properties
storeFile=gopherlife-release.keystore
storePassword=<ваш пароль>
keyAlias=<алиас>
keyPassword=<ваш пароль>
```

Ключ создаётся один раз:

```bash
keytool -genkeypair -v -keystore android/gopherlife-release.keystore \
  -alias gopherlife -keyalg RSA -keysize 2048 -validity 10000
```

Если файла `keystore.properties` нет, сборка проходит, но APK остаётся
неподписанным (установить на устройство не получится).

## Приёмка качества

**Полные условия задачи, правила процесса и разбор прошлых провалов — в файле
[`ТЗ.md`](ТЗ.md). Прочитать до любых правок.**

Перед выдачей сборки прогоняйте автотесты — они проверяют именно то,
что ломалось в прошлых версиях:

```bash
node tools/verify.js
```

5 независимых ревьюеров:

1. **Статический анализ** — синтаксис, синхронность `www/` и `assets/www/`,
   наличие запуска игры, палитра маскота, отсутствие мусора и секретов.
2. **Эмулятор браузера** — реальный boot `new Game().init()` и 630 кадров
   отрисовки по всем 7 сценам, проверка утечек.
3. **Функциональные клики** — навигация меню → карта → дом → магазин →
   статистика → назад и эффект действий (кормление реально повышает сытость).
4. **Целостность APK** — что внутри APK актуальные файлы, есть ресурс иконки
   и сборка подписана, а не debug.
5. **Реальный рендер** — игра запускается в настоящем Chrome, у канваса каждой
   сцены снимаются пиксели через `getImageData` и PNG. Падает, если кадр пустой
   («чёрный экран»), мало цветов или есть ошибки JS. **Ревьюеры 1–4 работают на
   заглушке canvas и ловят только логику — визуальные дефекты ловит только он.**

```bash
npm run render                       # только реальный рендер
npm run render -- --only=shop,home   # отдельные сцены
npm run render -- --shots=dir        # + сохранить PNG сцен
```

> Скриншоты в `preview/screens/` получены именно так. Для проверки нужен
> установленный Chrome (путь можно задать в `CHROME_BIN`).

Код выхода `0` — сборку можно отдавать.
