## 0. СНАЧАЛА — БЕЗОПАСНОСТЬ

Приватный ключ API RuStore, отправленный в переписке текстом, **считайте
скомпрометированным**: перевыпустите его в консоли (вкладка «Разработчик» или
«Компания» → меню **API RuStore** → «⋯» у ключа → «Заменить ключ») и сохраните так:

```bash
# скопировать приватный ключ из консоли RuStore в буфер обмена, затем:
node tools/rustore-publish.js save-key 2351032844 --clipboard
# вариант с явной передачей ключа (тогда он останется в истории команд):
node tools/rustore-publish.js save-key <keyId> <приватный ключ base64>
```

Ключ ложится в **связку ключей macOS** — в файлы проекта и в git он не попадает
(проверено автотестом: `verify.js`, блок 10).

## 3. ПЕРВАЯ ВЕРСИЯ — ТОЛЬКО ЧЕРЕЗ ВЕБ-КОНСОЛЬ

RuStore не даёт создать черновик версии через API, пока у приложения нет
активной версии (прямая цитата из документации: *«creation of a draft version is
only possible when there is an active app version available»*). Поэтому первую
версию загружаем руками — один раз, минут на десять.

1. Консоль → **Приложения** → `Gopher Life` → **Загрузить версию**.
2. Тип приложения: **Универсальное** (телефон/планшет), файл: `app-release.apk`.
3. Поля карточки копируйте из `store/CONSOLE_PASTE.txt` (там каждое поле отдельным
   блоком; полный текст — `store/card.txt`), медиа — из `store/`:
   иконка `icon-512.png`, скриншоты по порядку `01_menu.jpg` … `10_settings.jpg`.
4. **Возрастная категория**: 0+ (RuStore принимает 0+/6+/12+/16+/18+, рейтинга «3+» в RuStore нет).
5. **Категории**: тип «Игра», основная «Дети», дополнительная «Симуляторы»;
   **маркировка внутриигрового контента** — оставить пустой.
6. **Политика конфиденциальности**: `https://lemeshev.github.io/Gopher/privacy.html`
   (страница уже опубликована; либо свой URL).
7. **Безопасность данных**: приложение не собирает и не передаёт данные, рекламы
   и покупок нет, интернет не требуется. Разрешений приложение не запрашивает
   вообще — это видно в APK и проверяется автотестом.
8. Отправить на модерацию.

## 4. СЛЕДУЮЩИЕ ВЕРСИИ — ОДНА КОМАНДА

```bash
node tools/rustore-publish.js check                       # доступ, сухой прогон
node tools/rustore-publish.js status --go                 # что уже в магазине
node tools/rustore-publish.js all --go --email ВАШ@МЭЙЛ   # черновик + APK + скриншоты + на модерацию
```

Порядок внутри `all`: создать черновик (метаданные из `store/card.txt`) →
загрузить APK → загрузить 10 скриншотов → отправить на модерацию. После
модерации версия публикуется автоматически (`publishType: INSTANTLY`).

Без `--go` скрипт только рассказывает, что сделает (по умолчанию — сухой прогон,
так безопаснее).

## 5. ЧТО ПРОВЕРЕНО АВТОТЕСТАМИ (блок 10 в `tools/verify.js`)

- APK не запрашивает **ни одного разрешения** (`INTERNET`, `ACCESS_NETWORK_STATE`,
  `WAKE_LOCK` убраны как ненужные: игра полностью офлайн, страница грузится из
  `file:///android_asset`, `usesCleartextTraffic=false`);
- ключ RuStore не попадает в файлы проекта и в git;
- тексты карточки соответствуют лимитам RuStore (название ≤50, краткое ≤80,
  полное ≤4000, «что нового» ≤5000, FAQ ≤10 пар);
- политика конфиденциальности на месте и говорит правду (нет сбора данных,
  нет сети, нет рекламы и покупок, прогресс — только на устройстве);
- меню показывает настоящий прогресс ребёнка (уровень, опыт, монеты), а не нули.
