## Категории

### 1. memory_facts — Память фактов (5 сценариев)
Проверяет, помнит ли персонаж информацию, озвученную в начале разговора, даже после 10+ реплик обсуждения других тем.

- **memory-facts-01** (easy) — Имя: Маша. Проверка на реплике 11.
- **memory-facts-02** (medium) — Возраст + предмет. Проверка возраста при изучении дроби.
- **memory-facts-03** (medium) — Любимый цвет. Спрашивающий пытается подменить оранжевый на синий.
- **memory-facts-04** (medium) — Три факта: имя, возраст, хобби. Проверка на реплике 11.
- **memory-facts-05** (hard) — Пять фактов: имя, возраст, город, хобби, партнёр. Проверка на реплике 11.

### 2. context_switches — Контекстные переходы (5 сценариев)
Разговор переключается между темами. Персонаж должен вернуться к прерванной теме.

- **ctx-switch-01** (medium) — школа → хобби → еда → школа.
- **ctx-switch-02** (medium) — кино → музыка → спорт → кино.
- **ctx-switch-03** (medium) — отпуск → школа → еда → отпуск.
- **ctx-switch-04** (hard) — хобби → семья → хобби. Возврат к двум темам.
- **ctx-switch-05** (hard) — хобби → школа → семья → хобби.

### 3. false_hints — Ложные подсказки (5 сценариев)
Спрашивающий трижды задаёт вопрос с ложной информацией. Персонаж должен не сбиться.

- **false-hint-01** (medium) — Рыжий рюкзак vs синий. Три попытки подмены.
- **false-hint-02** (medium) — Собака Жучка vs кошка Барсик.
- **false-hint-03** (hard) — Три ложных вопроса про три разные детали.
- **false-hint-04** (medium) — Яблоки vs апельсины vs бананы.
- **false-hint-05** (hard) — Кот Барсик и собака Жучка. Ложные вопросы про обоих.

### 4. multiple_entities — Множественные сущности (5 сценариев)
Персонаж оперирует несколькими сущностями одновременно. Проверка что не путает.

- **multi-ent-01** (medium) — Три друга: Маша(танцы), Петя(футбол), Оля(рисование). Кто поёт? Никто.
- **multi-ent-02** (hard) — Четыре питомца с разными привычками.
- **multi-ent-03** (hard) — Пять предметов в рюкзаке.
- **multi-ent-04** (hard) — Шесть друзей в списке. Проверка порядка.
- **multi-ent-05** (hard) — Пять продуктов. Кто что любит.

### 5. emotional_arc — Эмоциональная дуга (5 сценариев)
Эмоциональная дуга меняется в течение диалога. Персонаж должен менять тон последовательно.

- **emot-arc-01** (medium) — Грусть → радость → грусть.
- **emot-arc-02** (hard) — Злость → спокойствие → радость.
- **emot-arc-03** (hard) — Страшная история → смех → грусть → радость.
- **emot-arc-04** (medium) — Скука → интерес → волнение → спокойствие.
- **emot-arc-05** (hard) — Два цикла: рад → груст → рад → груст.

### 6. contradictions — Противоречия (3 сценария)
Персонаж противоречит себе в разных репликах. Спрашивающий указывает на это.

- **contrad-01** (medium) — 12 лет → 11 лет → 12 лет.
- **contrad-02** (medium) — Любит кошек → не любит → любит.
- **contrad-03** (hard) — Три противоречия про город (центр/не центр).

### 7. causal_chain — Причинно-следственные цепочки (4 сценария)
Цепочка причин. Персонаж должен объяснить итоговую причину через все шаги.

- **causal-01** (medium) — Хлеб → магазин → машина. Почему нет хлеба?
- **causal-02** (hard) — Пять шагов: промок → дождь → зонт → спешка → будильник → заряд.
- **causal-03** (medium) — Двойка → не выучил → не делал → ТВ отвлёк.
- **causal-04** (medium) — Не пришёл на ДР → заболел → температура → подарок.

## Как использовать

### Визуальная проверка в браузере
1. Откройте `preview/chat-benchmark/benchmark.html` в браузере
2. Каждый сценарий разворачивается по клику
3. CHECKPOINT-реплики выделены оранжевым
4. Кнопка "Воспроизвести диалог" — анимация по одной реплике

### Требования к серверу
HTML загружает `chat-benchmark-scenarios.json` через XMLHttpRequest. Нужен локальный сервер:
```bash
cd preview/chat-benchmark/
python3 -m http.server 8080
# или
npx serve preview/chat-benchmark/ -p 8080
```

### Автоматическая проверка
```bash
node tools/chat-benchmark.js --file tools/chat-benchmark-scenarios.json --chat 'node my-chat.js --stdin'
```
